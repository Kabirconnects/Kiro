# Kiro 🐾

Kiro is an AI-powered desktop companion that lives on your screen and helps you code.

## Planned features

- 🐾 Multiple selectable companion characters
- 🤖 AI coding assistant
- 💻 Code generation, explanation, debugging, and project assistance
- 🔐 Authentication and user profiles
- 🌐 Browser-based companion/web app
- 🖥️ Desktop companion with an always-on-top animated character
- 📂 Permission-based file and project access
- 🧠 AI-powered actions with explicit user approval
- 📦 Installable desktop application
- 🌐 MERN-based backend and web architecture

## Roadmap

1. Authentication and user profiles
2. Browser application
3. Companion selection and character system
4. AI chat and coding assistance
5. Project/file integration with permissions
6. Desktop companion and animations
7. Packaging and installers

> Kiro is designed to make coding more interactive, personal, and fun.
